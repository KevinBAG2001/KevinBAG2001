# Portfolio (GitHub Pages)

Static site for **https://kevinbag2001.github.io**.

## Deploy

1. Create a public repository named `KevinBAG2001.github.io` on GitHub.
2. Copy the contents of this folder (`index.html`, `css/`, `js/`, `assets/`) to the **root** of that repository.
3. In the repo **Settings → Pages**, set source to deploy from branch `main` (root).
4. Wait a few minutes for the site to publish.

No build step required — open `index.html` locally or use any static host.
